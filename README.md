# Roomora

Roomora is a responsive room booking web application I built to explore frontend development and multi-user booking workflows.

The project includes separate User and Staff experiences, room browsing, booking management and promotional-code functionality using HTML, CSS and JavaScript.

## What I Worked On

I developed the frontend interface and booking workflows, including the User and Staff experiences and client-side data handling.

The project gave me more experience working with JavaScript application logic, browser storage, multi-page interfaces and maintaining consistent functionality across different user flows.

## Technical Notes

Roomora is a frontend prototype and does not currently use a backend or shared database. Booking and room data is stored using browser `localStorage`, while `sessionStorage` is used for the current user session.

The demo login is implemented client-side for prototype purposes and is not intended to represent production authentication.
